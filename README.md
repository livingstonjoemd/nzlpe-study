# NZLPE Part I: study game

Personal study tool for the NZ Legal System exam (Part I, 24 Nov 2026). Built on deck v12 (72 cards).

## What it trains
- **Law questions (159).** Holdings, tests, sections, splits. Wrong options are real authorities or common slips, so the picture never gives the answer away.
- **Facts to case (31).** Read a case's facts, name the card.
- **Which card applies? (42).** New fact patterns, not on any card, as in a problem question.
- **Put the test in order / Find the missing step.** Hansen's six steps, the review checklist, passing a Bill, the international law ladder and the other TEST cards.
- **Picture warm-up (72).** The memory hooks.
- **Exam room (43 prompts).** All 34 Part I questions from Nov 2021 to Jul 2026, paraphrased, plus 9 practice prompts on live issues and untested cards. Four timed stages: route (pick the cards, scored against a model route), plan (one box per limb), write (40 minutes), mark (automatic authority audit and form checks, then a 50-mark self-mark rubric, ways to land with their conditions, and traps).

Spaced review: right answers move a question up a box (back in 1, 2, 4, 8 days); wrong answers drop it to box 1 so it comes back first. The mastery map shows each suit's share at box 3 or higher.

## Files
- `data/cards.js`: the 72 v12 cards.
- `data/drills.js`: law questions, scenarios and the cite-audit keywords.
- `data/essays.js`: exam-room prompts, model routes, landings, traps and the rubric.
- `img/<card>.webp`: one picture per card.

## Notes
- Progress and essays are saved in the browser. Use Export to keep a copy.
- Past-paper prompts are paraphrased, not copied; the papers themselves are not in this repo.
- Cards with an open item (time-sensitive or unverified) can be skipped in settings. Check them before the exam.
